# 影武者 Kagemusha — Unity 骨架舞台原型 0.4.2

獨立 Unity 3D 原型，保留舊版「武士忍者互動表演」。以真人姿勢啟動六招，先驗證骨架、施術流程和舞台特效，再製作完整角色蒙皮。

## 開啟

雙擊上層「開啟影武者.command」，或開啟 `Builds/Kagemusha Stage.app`。預設啟動本機鏡頭，上半身／全身自動判斷。第一次需允許 macOS 相機權限。Unity 專案使用 6000.3.26f1；場景為 `Assets/Kagemusha/Scenes/Kagemusha.unity`。

|操作|用途|
|---|---|
|V|開啟真人鏡頭|
|D|切到 38 秒循環合成骨架示範；不是真人捕捉|
|C|重新定位人物中央與相對大小基準|
|T|進入／離開教學測試模式|
|1／2／3／4／5／6|預覽螺旋丸、水遁、刀光、分身、召龍、火遁|
|Space|清理特效與本次施術狀態|
|O／Tab|環繞視角／隱藏控制板|

自由演出時，換招由姿勢直接判斷，不需按選招鍵。數字鍵只供看特效，不能證明相機辨識成功。教學模式停用這些預覽鍵。

## 六招姿勢與效果

左右手指舞者本人的左右；舞台鏡像呈現。

|招式|動作順序|3D 呈現|
|---|---|---|
|螺旋丸|右掌停在右側胸腹前，左手繞右掌畫圈累積一圈；成形後右手舉過肩，再快速向前下方拋出|藍白旋轉球、螺旋線與成形後的四翼風刃，投出後沿手勢方向飛行|
|水遁・水龍彈|雙手靠近胸口中央結印集氣，停約一秒後，雙手向兩側推開到肩寬以上|水色長身龍、波紋與水粒子，朝雙手推出方向前進|
|拔劍與收劍|左手守左腰，右手在左腰握柄停約 0.3 秒，再向右上方斜拔；揮右臂斬擊。收劍直接雙手回到左腰握柄位置、保持約 0.55 秒；放開後才可重新拔劍|有刀身、刀鍔、刀柄的銀色武士刀及弧形刀光|
|影分身|上身前傾、雙臂向身後斜伸，雙手略向外展並留在鏡頭內，保持約 0.6 秒；不必真的跑|白煙中出現左右兩個青色骨架分身，約 5 秒內同步跟隨動作|
|龍脈召喚|頭頂雙掌靠近約 0.6 秒，再張開雙臂|大型綠金長身龍盤繞升起，包含龍角、龍鬚、爪、鱗脊及立體龍頭，約 8 秒|
|火遁|雙手在嘴前靠近結印約 0.6 秒；保持手位，轉動頭部及雙手引導方向|由頭／口前噴出橙黃火焰柱與火星，單次最長約 3 秒；鬆手或失去必要關節即停止|

姿勢參照經典動畫的動作輪廓，並配合普通鏡頭可辨識的手腕、手肘和軀幹位置調整。**目前沒有辨識手指結印**。螺旋丸必須實際畫圈，雙手靜止靠近不會充能；形成、舉起、投出分開判定。舊版抬單手選火、平舉雙臂選水、胸前交叉拔收刀、雙手放頭側開分身均已停用。

火遁方向結合頭部朝向與嘴前雙手方向；臉部方向不可用時，使用手位方向。這是頭部朝向估計，沒有辨識人物身分。需在實際鏡頭前驗收轉向幅度、鏡像手感和遮擋。

招式逐一檢查所需關節。分身需看見頭、雙肘、雙手；雙手完全藏在身後不觸發。稍微側身可讓前傾和後伸更清楚。單鏡頭的正面輪廓不能確認真實前後深度。集氣中斷會取消，恢復追蹤後不補發；保持同一姿勢不會持續重複召喚。分身、召龍以視覺表演為主；投射物、火焰與刀刃可命中舞台目標。

## 教學測試

六課可自由選擇。左側金色 3D 骨架循環示範，中央青色骨架跟隨真人。

1. 選課後先觀看步驟，按「開始練習」或 Enter。
2. 依右側提示完成各動作；會顯示確認時間、集氣進度、缺少的關節與修正提示。
3. 必須經過真人姿勢判定並釋放招式才過關。螺旋丸需完成成形、舉起、投出；劍術需完成拔劍、斬擊、回左腰停住收劍；火遁需噴出後再轉向至少約 12°。
4. 過關後按「下一招」，R 重練；左右方向鍵選課，Esc 返回演出。完成紀錄僅保留本次執行期間。

重新定位、重開鏡頭會重設本課練習。合成演示與手動特效不計成績。啟動參數 `--tutorial` 直接開教學；`--demo` 供合成示範。

## 鏡頭與表演區

設備未定，第一輪排練以單人、固定廣角鏡頭、獨立螢幕為基準：

- 鏡頭距離先試約 3.5–4 公尺，高度約 1.2–1.4 公尺，朝軀幹中心。這些是架設起點，程式不會量測公尺。
- 預留約寬 3 × 深 2 公尺動作區，標記中央站位。抬手、伸臂時頭手腳仍須入鏡，保留約 10% 餘裕。
- 近距離也可只拍上半身；雙肩、肘、手腕及頭部需留在畫面內。先用均勻正面照明和有對比的背景。
- 初版避免多人交錯、快速翻滾、長時間背對鏡頭。相機不要同時拍到投影上的人體，避免追蹤投影角色。
- 移動鏡頭、換舞者或主角配對錯誤時按 C。先測靜止、左右移動、伸臂、各招步驟，再加速。

左右位移依影像座標映射舞台。雙肩影像跨度相對首次入鏡或 C 定位的大小，用來推估舞台前後位置；透視讓靠近的人物較大、退後較小，限制約 0.65–1.45 倍。這是相對影像大小，轉身、遮擋與寬鬆衣服都可能影響估計。上半身模式中灰色下肢為站姿參考。

啟動時優先鎖定中央較大的前景主角，再依肩位和大小配對。背景路人不直接中斷主角；配對不明、位置跳變或主角失去時暫停施術。這是空間配對，人物交錯時仍需排練。

## 捕捉與驗證邊界

macOS 14+ 原生 Apple Vision 在本機推論。快速 2D 關節帶動 XY，全身模式另由背景 3D 推論補充肢體 Z；上半身依可見平面姿態解算。骨長修正前的影像平面關節用於姿勢判斷，修正後的 3D 骨架用於顯示，避免固定骨長改變施術輪廓。

頭部、17 關節球／骨管、刀、龍、能量球、火焰、煙和敵人均在 Unity 3D 場景中。龍與特效為程序生成的風格原型，尚未製作正式雕模與角色外殼。單鏡頭不是精密動捕，交叉、遮擋、轉身及高速動作仍需真人量測；畫面上的推論毫秒數不是鏡頭到螢幕的端對端延遲。

程式不錄影或上傳相機影像。本機應用程式資料夾的 `tracking-status.json` 僅記錄模式、關節信心、位置、計數及錯誤提示。沒有網路多人或音樂同步功能。

0.4 自動驗證涵蓋六招、上半身／全身、遠近影像大小、缺手取消、保持單發、舊姿勢停用、鏡像前傾、頭部轉向及全部六課。靜態全身照片驗證包含 17 關節、頭朝向資料、空白拒絕與重設；照片耗時不能代替現場效能。0.3 的真人測試紀錄保留於 Evidence，只能證明當時版本；0.4 六招仍需舞者逐招真人驗收。

0.4.1 針對真人回報修正：水遁集氣後的連續推掌不再被螺旋丸起手搶走，推掌時間放寬；新增 0.6／1.2／1.8 秒連續推掌驗證。收劍改成直接回左腰握柄停住，教學與示範同步更新；保持收劍姿勢不會立即重新拔劍。結果見 `Evidence/water-sheath-verification.txt`。

0.4.2 為分享交接版：改用可隨專案再散布的 Noto Sans TC 字型，來源與完整 OFL 授權見 `THIRD_PARTY_NOTICES.md` 及 `Assets/Kagemusha/Fonts/NotoSansTC-OFL.txt`；Mac app 也附授權文件。最低系統欄位同步為 macOS 14.0。六招與水遁／收劍判定維持 0.4.1 的修正，最新修正後真人驗收仍待完成。
